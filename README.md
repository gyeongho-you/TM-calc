# TM-calc

테이밍 마스터 2 성장률 계산 레이어 (Android 11+).
게임 위에 떠 있는 "계산" 버튼을 누르면 소환수 정보 화면을 한 장 찍어 읽고,
총 성장률(실제 / 인게임), 능력치별 등급, 강화별(최대 +5강) 예상 등급을 보여 줍니다.

## 설치
[Releases](../../releases/latest) 에서 `TM-calc.apk` 를 받아 설치합니다.

1. 앱 실행 → ① 다른 앱 위에 표시 허용 → ② 접근성에서 켜기 → ③ 레이어 시작
2. 접근성이 회색으로 막혀 있으면: 앱 정보 → ⋮ → "제한된 설정 허용" 후 다시 켜기
3. 끌 때는 "계산" 버튼을 꾹 눌러 아래 쓰레기통에 놓기

화면은 버튼을 누를 때만 한 장 찍고 폰 안에서만 처리합니다 (인터넷 권한 없음).

## 도감
- 기본 도감: `app/src/main/assets/pets.json` (엑셀 계산기의 '소환수S도감' 시트, `tools/update_pets.py` 로 생성)
- 앱의 "도감 관리"에서 추가/수정하면 폰에 따로 저장되고, JSON 으로 저장/올리기 할 수 있습니다.
- `도감.json`: PC 에서 고치기 쉬운 전체 도감. 고친 뒤 앱의 "JSON 올리기"로 넣으면 바뀐 소환수만 반영됩니다.

```json
{"이름":"라르곤","등급":"전설","속성":"불","타입":"야수","초기치":[14,9,10,114],"S성장률":[3.54,2.32,2.57,27.67],"만렙S":[541,356,394,4237]}
```
배열 순서는 항상 공, 방, 순, 체.

## 빌드
JDK 17~21, Android SDK 35. 경로에 한글이 있으면 빌드가 실패하므로 영문 경로에서:

```
gradlew testDebugUnitTest assembleRelease
```
결과: `app/build/outputs/apk/release/app-release.apk`
